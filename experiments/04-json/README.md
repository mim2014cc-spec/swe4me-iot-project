# การทดลองที่ 5: JSON + ข้อมูลจากอุปกรณ์

## วัตถุประสงค์

เรียนรู้ว่าอุปกรณ์ส่งข้อมูลเซ็นเซอร์ในรูปแบบ JSON อย่างไร ซึ่งใกล้เคียงกับวิธีที่ ESP32 ส่งข้อมูลไปยัง MQTT ในโปรเจคจริง

## JSON คืออะไร?

JSON ย่อมาจาก JavaScript Object Notation เป็นรูปแบบข้อความที่ใช้ส่งข้อมูลแบบง่าย เช่น:

```json
{
  "device_id": "team01",
  "temperature": 31.2,
  "humidity": 55.5,
  "status": "ok"
}
```

อุปกรณ์สามารถส่งข้อมูลแบบนี้ไปยังเซิร์ฟเวอร์หรือ broker ได้

## ขั้นที่ 1: รันสคริปต์

```bash
python payload_demo.py
```

## สคริปต์นี้ทำอะไร

- สร้าง dictionary ใน Python
- แปลงข้อมูลเป็นข้อความ JSON ด้วย `json.dumps()`
- แสดงผลข้อความที่ถูกส่ง
- แสดงให้เห็นว่าเซิร์ฟเวอร์สามารถอ่านและแยกข้อมูลได้

## กิจกรรมฝึกปฏิบัติ

ลองเปลี่ยนค่าตัวอย่างเหล่านี้:

- device_id เป็นชื่อของกลุ่มหรือชื่อของคุณ
- temperature เป็นค่าตัวเลขใหม่
- humidity เป็นค่าตัวเลขใหม่

จากนั้นรันสคริปต์อีกครั้งแล้วสังเกตผลลัพธ์

## ทำไมเรื่องนี้สำคัญ?

ในโปรเจคหลัก ESP32 จะส่งค่าของเซ็นเซอร์ในรูปแบบ JSON ผ่าน MQTT Flask จะได้รับข้อความนั้น ตรวจสอบข้อมูล แล้วบันทึกลง SQLite

## คำถามสำหรับการคิดต่อ

- ทำไมเราจึงส่งข้อมูลเป็น JSON แทนที่จะส่งข้อความธรรมดา?
- ฟิลด์ใดบ้างที่จำเป็นสำหรับข้อมูลเซ็นเซอร์?
- เรื่องนี้เกี่ยวข้องกับการทดลอง MQTT อย่างไร?
