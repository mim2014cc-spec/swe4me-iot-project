# การทดลองที่ 3: Flask

## วัตถุประสงค์

เรียนรู้ว่าแอป Flask แบบง่ายทำงานอย่างไรและวิธีจัดการ route

## ขั้นที่ 1: ติดตั้ง Flask

```bash
pip install flask
```

## ขั้นที่ 2: รันแอป

```bash
python app.py
```

แล้วเปิดหน้านี้ในเบราว์เซอร์:

```text
http://localhost:5000
```

> คำแนะนำ: ให้รันแอปเพียงตัวเดียวต่อครั้งเท่านั้น ห้ามเปิดหลายหน้าต่างพร้อมกันบนพอร์ตเดียวกัน เพราะจะทำให้เซิร์ฟเวอร์ชนกันหรือเริ่มซ้ำ ๆ

## สิ่งที่ควรสังเกต

- เว็บเบราว์เซอร์ส่ง request ไปที่ `/`
- Flask จะจัดการ request ด้วยฟังก์ชัน Python
- ฟังก์ชันจะคืนค่า HTML กลับไปให้เบราว์เซอร์แสดงผล

## การทดลองง่าย ๆ

ลองเปลี่ยนบรรทัดนี้:

```python
return "Hello, Flask!"
```

เป็น:

```python
return "My first Flask app"
```

แล้วรันเซิร์ฟเวอร์อีกครั้งและ refresh หน้าเว็บดู

- ทำไม Flask จึงมีประโยชน์สำหรับแดชบอร์ด?
- Flask เชื่อมต่อกับ MQTT และ SQLite ในโปรเจคหลักอย่างไร?
