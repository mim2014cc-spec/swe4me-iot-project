# การทดลองที่ 5: ngrok + Flask

## วัตถุประสงค์

ทำความเข้าใจว่า `ngrok` ช่วยเปิดแอปที่ทำงานบนเครื่องเราให้เข้าถึงจากอินเทอร์เน็ตได้อย่างไร โดยใช้ Flask ที่รันบน localhost:5000 เป็นตัวอย่างจริง

## เครื่องมือที่ใช้

- Python
- Flask
- ngrok

## ขั้นที่ 1: เริ่ม Flask app ก่อน

เปิด Terminal ในโฟลเดอร์ `01-flask` และรัน:

```bash
python app.py
```

ตอนนี้ Flask จะทำงานที่:

```text
http://localhost:5000
```

## ขั้นที่ 2: เปิดให้เข้าถึงด้วย ngrok

เปิด Terminal ขึ้นมาอีกหน้าต่างแล้วรัน:

```bash
ngrok http 5000
```

ngrok จะพิมพ์ URL สาธารณะออกมา เช่น:

```text
https://abcd1234.ngrok-free.app
```

ให้เปิด URL นั้นในเว็บเบราว์เซอร์เพื่อดูว่าแอป Flask ของเราเข้าถึงได้จากภายนอกแล้ว

## สิ่งที่ควรสังเกต

- Flask ยังทำงานบนเครื่องเราอยู่ที่ localhost:5000
- ngrok จะสร้าง tunnel จากอินเทอร์เน็ตไปยัง port 5000 ของเครื่องเรา
- เราไม่ได้ต้องสร้างเว็บเซิร์ฟเวอร์ใหม่แยกต่างหาก เพราะแอปหลักของเราคือ Flask แล้ว

## คำถามสำหรับการคิดต่อ

- ทำไมเราจึงต้องใช้ ngrok ในโปรเจคนี้?
- ความต่างระหว่างแอปที่ทำงานบนเครื่องเราและแอปที่เปิดให้คนอื่นเข้าถึงได้คืออะไร?
- ทำไมไม่ควรเปิดหลายแอปบนพอร์ตเดียวกันในเวลาเดียวกัน?
- ทำไมการทดสอบผ่าน ngrok จึงเหมาะกับการแสดงผล prototype ก่อน deploy จริง?
