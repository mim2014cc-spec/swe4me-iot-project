# การทดลองที่ 4: SQLite

## วัตถุประสงค์

เรียนรู้ว่า SQLite เก็บข้อมูลแบบง่าย ๆ ในฐานข้อมูล local อย่างไร

## ขั้นที่ 1: รันสคริปต์

```bash
python database_demo.py
```

## สคริปต์นี้ทำอะไร

- สร้างไฟล์ฐานข้อมูลชื่อ `demo.db`
- สร้างตารางชื่อ `sensor_logs`
- ใส่ค่าตัวอย่างของอุณหภูมิและความชื้น
- อ่านข้อมูลกลับมาแล้วแสดงผลทางหน้าจอ

## คำถามสำหรับการคิดต่อ

- ทำไม SQLite จึงมีประโยชน์กับโปรเจคเล็ก ๆ?
- มันต่างจากฐานข้อมูลใหญ่ ๆ อย่างไร?
- ทำไมเราจึงต้องเก็บค่าข้อมูลเซ็นเซอร์ลงฐานข้อมูล?
