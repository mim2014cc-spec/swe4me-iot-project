# การทดลองเล็ก ๆ สำหรับผู้เริ่มต้น

โฟลเดอร์นี้ออกแบบมาเพื่อเป็นเส้นทางการเรียนรู้สั้น ๆ สำหรับนักเรียนที่ยังใหม่กับ IoT และเครื่องมือทางเว็บ

แต่ละการทดลองจะนำเสนอเครื่องมือหรือเทคโนโลยีหนึ่งอย่างที่ใช้ในโปรเจคนี้:

- ngrok: เปิดแอปที่รันอยู่ในเครื่องให้เข้าถึงจากอินเทอร์เน็ตได้
- MQTT: ส่งข้อความระหว่างอุปกรณ์ผ่านตัวกลางกลาง (broker)
- Flask: สร้างเว็บแอปแบบง่าย
- SQLite: เก็บและอ่านข้อมูลเซ็นเซอร์แบบเล็ก ๆ

## วิธีใช้งาน

1. เปิดโฟลเดอร์หนึ่งโฟลเดอร์ต่อครั้ง
2. อ่าน README ในโฟลเดอร์นั้นก่อน
3. รันสคริปต์ด้วย Python
4. สังเกตผลลัพธ์ที่ปรากฏ
5. เปลี่ยนค่าบางค่าแล้วทดลองรันอีกครั้ง

## ลำดับที่แนะนำ

1. เริ่มด้วย Flask
2. จากนั้น SQLite
3. ตามด้วย MQTT
4. จากนั้น JSON
5. จบด้วย ngrok

ลำดับนี้ช่วยให้นักเรียนเข้าใจแอปที่ทำงานในเครื่องก่อน แล้วค่อยเปิดให้คนภายนอกเข้าถึงได้ โดยการทดลอง ngrok จะใช้ Flask ที่กำลังทำงานบน localhost:5000 เป็นจุดเริ่มต้น
