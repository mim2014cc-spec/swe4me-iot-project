# การทดลองที่ 2: MQTT

## วัตถุประสงค์

ทำความเข้าใจว่า MQTT ทำงานอย่างไรโดยใช้ broker แบบสาธารณะ

## เครื่องมือที่ใช้

- Python
- paho-mqtt

## แนวคิดสั้น ๆ

MQTT ประกอบด้วย:

- Publisher: ผู้ส่งข้อความ
- Subscriber: ผู้รับข้อความ
- Broker: ระบบกลางที่ช่วยส่งต่อข้อความ
- Topic: ชื่อช่องทาง เช่น `demo/team01/test`

## ขั้นที่ 1: ติดตั้ง dependency

ถ้าจำเป็น ให้ติดตั้งด้วยคำสั่ง:

```bash
pip install paho-mqtt
```

## ขั้นที่ 2: รันตัวรับข้อความ (subscriber)

เปิด Terminal หนึ่งหน้าต่างแล้วรัน:

```bash
python subscribe_demo.py
```

โปรแกรมนี้จะรอรับข้อความอยู่

## ขั้นที่ 3: รันตัวส่งข้อความ (publisher)

เปิด Terminal อีกหน้าต่างแล้วรัน:

```bash
python publish_demo.py
```

คุณจะเห็นข้อความถูกส่งและได้รับกลับ

## สิ่งที่ควรสังเกต

- ตัวส่งข้อความจะส่งข้อมูลแบบ JSON-like text
- ตัวรับข้อความจะได้รับข้อมูลจาก broker
- ข้อความถูกส่งไปยัง topic แทนที่จะส่งตรงถึงอุปกรณ์หนึ่งเครื่อง

## คำถามสำหรับการคิดต่อ

- ทำไมเราจึงใช้ topic แทนการส่งข้อความไปยังอุปกรณ์เพียงเครื่องเดียว?
- ทำไม MQTT จึงมีประโยชน์สำหรับ IoT?
- broker กับการสื่อสารแบบตรงต่างกันอย่างไร?
